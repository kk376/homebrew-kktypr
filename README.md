# homebrew-kktypr

Homebrew tap for KKTypr.

## Installation

```bash
brew tap kk376/kktypr
brew install kktypr
```

Or install directly:

```bash
brew install kk376/kktypr/kktypr
```

## Formulas

- **kktypr**: Terminal touch typing academy and developer syntax trainer written in pure Rust by Kushagra Kumar (kk376).
